WIPRO CAPSTONE PROJECT 

I am Adrika Bhakta, a B.Tech CSE (AI & ML) student, and this project was developed as part of my Wipro Capstone Project. The project focuses on developing a scalable Selenium Python Automation Framework for an E-Commerce application, automating key functionalities such as user login and product search.

The framework is built using Selenium WebDriver, Python, PyTest, Unittest, and the Page Object Model (POM). It also incorporates configuration management, CSV-based test data handling, reusable utility classes, automated screenshots on test failure, and HTML test reporting to create a structured and maintainable automation framework.

The outcome of the project is a reusable and organized test automation solution that reduces manual testing effort and improves test execution, debugging, and reporting. The framework can be easily extended with additional test cases and functionalities, demonstrating practical skills in Python automation, software testing, framework development, and quality assurance.
